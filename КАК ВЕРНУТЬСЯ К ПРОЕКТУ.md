# Как вернуться к работе над проектом

Этот чат идёт в **Claude Code (терминал)**, у него нет прямой кликабельной ссылки,
как у обычного сайта. Поэтому «ярлык чата» работает так:

## Вариант 1 — продолжить в этом же терминале
Открой Терминал и выполни:
```
cd ~/Desktop/MMORPG
claude
```
Claude автоматически подхватит контекст проекта из файлов `КОНТЕКСТ.md` и кода.
Если нужно продолжить именно прошлый диалог — запусти `claude --continue` (последняя сессия)
или `claude --resume` (выбрать из списка).

## Вариант 2 — веб-версия
Файл `Открыть чат проекта.webloc` открывает claude.ai/code в браузере.

## Главное
Весь контекст проекта живёт в файле **КОНТЕКСТ.md** — он и есть «память» проекта.
Достаточно открыть папку MMORPG в Claude, и можно продолжать с любого места.
