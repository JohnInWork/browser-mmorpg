# data/ — контент игры (отдельно от кода)

Главный принцип масштабирования: **контент — это данные, а не код.**
Сотни мобов/предметов/ресурсов — это записи в JSON, которые читает ОДНА система.
Добавить новое = дописать запись здесь, не трогая логику.

## Файлы

- **mobs.json** — типы мобов (`types`) и их расстановка на карте (`spawns`).
  Используется `server/mobs.js`. ✅ подключено.
- **default-map.json** — стартовая карта (тайлы). Используется `server/world.js`. ✅ подключено.
- **items.json** — предметы/оружие. 🟡 КАРКАС на будущее (пока кодом не используется).
- **resources.json** — ресурсы для добычи. 🟡 КАРКАС на будущее (пока кодом не используется).

## Как добавить моба
В `mobs.json` → `spawns` дописать `{ "x": .., "y": .., "type": "passive" }`.
Новый ТИП моба — добавить запись в `types` (цвет, hp, урон, поведение).
